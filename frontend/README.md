# Network Traffic Anomaly Detection Frontend

This frontend application provides a user interface for the Network Traffic Anomaly Detection system, allowing for data exploration, model training, and anomaly detection through an interactive web interface.

## Features

- **Data Upload & Exploration**: Upload network traffic data and explore its characteristics
- **Model Training & Evaluation**: Train and evaluate various machine learning models
- **Anomaly Detection**: Detect anomalies in new network traffic data
- **Interactive Visualizations**: Visualize results using interactive Plotly charts
